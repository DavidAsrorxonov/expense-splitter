# Query plans

Generated by `npm run plans` against the seeded database.

## Active members of a group

```sql
SELECT * FROM members WHERE group_id = ? AND archived_at IS NULL
```

```text
SEARCH members USING INDEX idx_members_group_name_active (group_id=?)
```

## Expense list, newest first

```sql
SELECT * FROM expenses WHERE group_id = ? AND archived_at IS NULL ORDER BY spent_on DESC
```

```text
SEARCH expenses USING INDEX idx_expenses_group_spent_on (group_id=?)
```

## Monthly totals

```sql
SELECT strftime('%Y-%m', spent_on) AS month, SUM(amount_minor) FROM expenses WHERE group_id = ? AND archived_at IS NULL GROUP BY month
```

```text
SEARCH expenses USING INDEX idx_expenses_group_spent_on (group_id=?)
USE TEMP B-TREE FOR GROUP BY
```

## All splits for one member

```sql
SELECT * FROM splits WHERE member_id = ?
```

```text
SEARCH splits USING INDEX idx_splits_member (member_id=?)
```

## Settlements of a group, newest first

```sql
SELECT * FROM settlements WHERE group_id = ? ORDER BY created_at DESC
```

```text
SEARCH settlements USING INDEX idx_settlements_group_created (group_id=?)
```
